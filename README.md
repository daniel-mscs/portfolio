## 👋 Sobre

Sou técnico de enfermagem e estudante de **Engenharia de Software (2025–2029)**.
A rotina no hospital me ensinou a trabalhar sob pressão, a ter atenção aos detalhes e a entender o problema de quem está do outro lado,
e é isso que levo para o código.

Hoje meu foco é **back-end com Java e Spring Boot**, e busco uma vaga de **estágio ou júnior**.

## ✨ O que tem no site

| Seção | Destaque |
| --- | --- |
| **00 · Hero** | Terminal estilo Windows com comandos sendo digitados em loop |
| **01 · Sobre** | Crachá que balança, com dados de contato |
| **02 · Habilidades** | Front-end, Back-end, Dados e Ferramentas, entrando em zigue-zague |
| **03 · Projetos** | Scroll horizontal fixado, com barra de progresso, mockup de navegador ou celular e lightbox para ampliar |
| **04 · Trajetória** | Linha do tempo de experiência e formação |
| **05 · Contato** | Cartões de e-mail, WhatsApp, LinkedIn e GitHub |

**Detalhes de interação**

- Seções reveladas no scroll, com entradas pelos lados e em sequência
- Brilho que segue o mouse e explosão de partículas e símbolos de código no clique
- Barra e contador de progresso de leitura
- Logo com extensão digitando (`.dev` → `.html` → `.css` → `.js` → `.java`)
- Respeita `prefers-reduced-motion` e tem layout próprio para celular

## 🚀 Rodando localmente

```bash
git clone https://github.com/daniel-mscs/portfolio.git
cd portfolio
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```

## 📁 Estrutura

```
src/
├── components/
│   ├── Navbar.jsx        # menu numerado + logo digitando
│   ├── Hero.jsx          # apresentação + terminal
│   ├── About.jsx         # sobre + crachá + componente Terminal
│   ├── Stack.jsx         # habilidades em grupos
│   ├── Projects.jsx      # scroll horizontal + lightbox
│   ├── Timeline.jsx      # experiência e formação
│   ├── Contact.jsx       # cartões de contato
│   ├── Footer.jsx
│   ├── CursorFX.jsx      # brilho e partículas do cursor
│   └── ScrollProgress.jsx
├── hooks/
│   └── useScrollReveal.js
├── assets/               # prints dos projetos
└── index.css             # variáveis, reveal e animações globais
```
